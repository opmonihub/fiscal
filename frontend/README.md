# Frontend fiscal

Este repositório contém os módulos de conteúdo próprios do painel, em `src/content/dashboard`.
A infraestrutura do Data App, dependências e dados privados locais não são distribuídos aqui.
Os módulos usam a API pública `data-app-public.jsx` do ambiente local. Um clone isolado não é uma aplicação autônoma pronta para execução.

O arquivo local `src/data.json` e as prévias XML são privados e ignorados pelo Git. Textos e componentes versionados devem continuar genéricos, sem nomes, identificadores ou valores de empresas.
